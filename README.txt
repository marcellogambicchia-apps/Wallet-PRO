Wallet-PRO 3.0.0 - candidata alla release ufficiale
Base: Wallet-PRO 2.3.11 TEST.
Modifiche: icona Dashboard multicolore; pannello Aggiungi piu stretto e posizionato sopra la barra di navigazione; numero versione e cache aggiornati.
Non sono state modificate le funzioni di importazione, backup, deduplicazione e dashboard.
Prima della pubblicazione definitiva: verificare su Safari Mac e iPhone l'apertura del menu Aggiungi, la barra sempre visibile e il funzionamento offline.
Conservare la versione 2.3.11 TEST e fare backup JSON dei dati prima di aggiornare.
